Seed Data

Seeding never runs automatically — nothing happens until you click one of the buttons below. Each click adds a batch of items/users; packs are allowed to overlap in titles — items are deduplicated by (title, release year) against what's already in the catalog, so re-seeding an overlapping pack only ingests the titles not yet present (users are not deduplicated). A Used badge marks a source already loaded before — loading it again asks for confirmation first. Each card's Unseed button removes exactly the items and/or users that source added (and forgets it was loaded, so it can be reseeded from scratch). Use the Items/Users pages for everything else.
